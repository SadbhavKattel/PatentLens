## Dataset

- 3,000 US patents under CPC subclass **G06N3** (neural network architectures), title + abstract text, real citation graph (`data/raw/patents_g06n3_wide.csv`).
- Citation ground truth: 127 of 3,000 patents (4.2%) cite at least one other patent that also falls inside the sample — 147 usable citation pairs total.
- This is the same-size corpus the original notebook used. Scaling to 40–50k+ patents via BigQuery is wired up in [`src/patentlens/data_fetch.py`](src/patentlens/data_fetch.py) but requires a GCP project to run — see that file's docstring. Everything below will re-run unchanged once a larger `data/raw/patents_g06n3_wide.csv` is in place.

## Methodology

**Models compared:**

| Model | Type |
|---|---|
| TF-IDF | Lexical, unigrams+bigrams, 5000-term vocabulary |
| BM25 | Lexical, probabilistic ranking |
| LSA | TF-IDF + Truncated SVD (100 components) |
| MiniLM | General-purpose sentence embeddings (`all-MiniLM-L6-v2`) |
| PatentSBERTa | Sentence embeddings fine-tuned on patent claims (`AI-Growth-Lab/PatentSBERTa`) |
| Hybrid | BM25 + PatentSBERTa combined via Reciprocal Rank Fusion (rrf_k=60) |

**Evaluation:** for every patent with at least one in-sample citation, rank all other patents by similarity/score and check whether the true cited patent(s) land near the top. This is a proxy metric — patent citations are a legal/prior-art decision, not a pure text-similarity judgment — but it's the only ground truth available without manual labeling.

**Metrics:** Recall@k, Precision@k, NDCG@k (k=5,10,20), and MRR, each with a 95% bootstrap confidence interval (2,000 resamples). NDCG additionally rewards ranking a true citation *higher* within the top k, not just including it — Recall@k alone can't distinguish a citation at rank 1 from one at rank 20.

**Significance:** a paired bootstrap test (5,000 resamples, same queries for both models each time) checks whether the top model by MRR is *actually* better than each alternative, not just higher on a bar chart.

### Is BM25 actually the best model, or just highest on the chart?

Paired bootstrap test, BM25 vs. each alternative, on MRR:

| Compared to | Mean MRR gap | 95% CI | p-value | Significant at 0.05? |
|---|---|---|---|---|
| PatentSBERTa | +0.0543 | [0.020, 0.093] | 0.0008 | **Yes** |
| TF-IDF | +0.0270 | [0.003, 0.057] | 0.0232 | **Yes** |
| LSA | +0.0355 | [-0.001, 0.075] | 0.0536 | No (borderline) |
| MiniLM | +0.0084 | [-0.030, 0.047] | 0.6656 | No |
| Hybrid | +0.0038 | [-0.020, 0.030] | 0.7816 | No |

**Takeaway: at this sample size, BM25 is only confidently better than TF-IDF and PatentSBERTa.** It is statistically indistinguishable from MiniLM and the Hybrid model — the gap between them could easily be noise from a ~150-pair evaluation set. Don't report "BM25 wins" without this caveat; report "BM25, MiniLM, and Hybrid are statistically tied for best."

## Key findings

1. **No single model is definitively best** — see the significance test above. BM25, MiniLM, and the BM25+PatentSBERTa hybrid all land in the same statistical tier.
2. **PatentSBERTa underperformed general-purpose MiniLM**, despite being fine-tuned specifically on patent text — a genuine negative result, not what was expected going in. Likely explanation: PatentSBERTa was trained on patent *claims* (dense, formal legal language) and on a CPC-classification objective, while this evaluation feeds it *title + abstract* text and asks it to predict citations — a different text distribution and a different task than what it was tuned for.
3. **LSA is the weakest model** — compressing to 100 components keeps only ~24% of the original TF-IDF variance, losing more signal than it's worth.
4. **Ceiling effect**: even the best model only reaches Recall@20 ≈ 0.32. Patent citations reflect legal/prior-art judgment as much as topical similarity, so no text-only retrieval model should be expected to approach 100% — this matches the original notebook's conclusion and held up under a more rigorous evaluation.
5. **Patent-specific text cleaning (stripping boilerplate legal words) helps lexical models (TF-IDF, BM25) more than semantic ones** — consistent with the original finding, since embedding models already look past individual boilerplate tokens.

## Limitations

- **Ground truth is small**: 147 pairs from 3,000 patents (4.2% coverage) is the single biggest source of uncertainty in every number above — it's why several models are statistically tied. Scaling the corpus (via `src/patentlens/data_fetch.py`) increases the chance that a patent's citations land inside the sample, which directly tightens these confidence intervals.
- **Citation-based evaluation is a proxy.** A model that's "wrong" about a citation may still be topically on point — citations are filed for legal reasons (prior art disclosure requirements), not because two patents read as similar.
- **PatentSBERTa was evaluated on title+abstract, not claims** — its original training domain. Re-running with claims text (if available from the data source) might change its ranking substantially.
